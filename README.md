# Doggo Additions
A Filament Minecraft datapack because I got bored.

Adds various small items that are more for fun than utility.

# Requirements
This datapack can only run on a Fabric server, as Filament is a Fabric mod.

[Filament](https://modrinth.com/mod/filament) because that's the entire premise of the custom items.

[Fabric API](https://modrinth.com/mod/fabric-api) because Fabric mods love it.

[Polymer](https://modrinth.com/mod/polymer) so people don't need to install mods to use the custom items.

## Recommended mods for clients
[Remove Reloading Screen](https://modrinth.com/mod/rrls): Since custom textures are used, the server will load a custom resource pack, so removing the loading screen would help players to not be stuck loading every time they join.

[Filament](https://modrinth.com/mod/filament): Having Filament as a client treats the item as a genuine modded item instead of a vanilla item with special properties, so you can see it in the creative inventory and /give. Plus it probably would help with some minor bugs.

<img width="272" height="160" alt="bigFeather" src="https://github.com/user-attachments/assets/da281bbd-b2dc-4062-af12-2a58852b977a" />
